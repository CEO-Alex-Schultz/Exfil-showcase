## О проекте

**Exfil** - это продвинутый десктопный музыкальный плеер, который объединяет в себе лучшие алгоритмы подбора музыки и доступ к трекам в высоком качестве. Приложение использует рекомендательную систему Spotify для поиска и подбора метаданных, при этом фактически загружая аудиофайлы и обложки с YouTube Music и SoundCloud. 

Проект создавался с упором на скорость работы, безопасную архитектуру авторизации и стильный визуальный опыт.

## Что реализовано

- 🔐 **Безопасная авторизация:** Система входа на основе токенов, которые надежно шифруются и хранятся в базе данных PostgreSQL.
- 🧠 **Умные рекомендации:** Интеграция со Spotify API для глобального поиска, составления персонализированных рекомендаций и подбора похожих треков на основе прослушанного.
- 🎵 **Мульти-сорсинг аудио:** Автоматический поиск, получение ссылок и скачивание самих аудиофайлов в высоком качестве, а также обложек альбомов с YouTube Music и SoundCloud.
- 💾 **Локальная медиатека и кэширование:** Возможность добавления треков в "Избранное" и их скачивания на клиент для офлайн-прослушивания. Для обеспечения моментального отклика метаданные треков и прямые ссылки кэшируются в PostgreSQL.
- 🎨 **Современный UI/UX:** Плавный интерфейс, написанный на QML. Разделен на интуитивные экраны: «Главная», «Рекомендации» и «Избранное». Дизайн дополнен геометричной типографикой, анимациями звуковых волн (эквалайзеров) и общей киберпанк-стилистикой для полного погружения.

## Архитектура и техническая реализация

### 🖥️ Frontend (Интерфейс на QML)
- Асинхронная подгрузка обложек и списков треков, чтобы интерфейс не зависал во время сетевых запросов.
- Реализация кастомных компонентов плеера (прогресс-бары, визуализаторы аудио, кнопки управления).

### ⚙️ Backend & API (C++)
- Модуль сетевых запросов (Network Access Manager) для асинхронного взаимодействия со Spotify API (OAuth 2.0, парсинг JSON-ответов).
- Сложная логика матчинга (сопоставления): получение названия трека от Spotify и его фоновый поиск на YT Music / SoundCloud для извлечения прямой ссылки на аудиопоток.
- Файловая система: менеджер загрузок для сохранения аудиофайлов в локальную директорию пользователя с отслеживанием прогресса.

### 🗄️ База данных (PostgreSQL)
- Хранение связок пользователей, защищенных токенов авторизации и их сессий.
- Реляционная структура для связи пользователей с их избранными треками.
- Индексирование URL-ссылок и названий треков для сверхбыстрого доступа без необходимости повторного обращения к внешним API.
